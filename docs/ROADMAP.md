# HyCode 实施路线

2026-10-22 / build 28：Web 全量目标和逐项状态集中在 [WEB_TOOLS.md](WEB_TOOLS.md)。本批接入原生 Web 语义、编辑导航、修改预览、package 脚本/依赖工具和固定服务打包。Web 调试、测试树/覆盖率、ESLint/Prettier 专用适配和更多框架继续逐项验收，不能因脚本能运行就标为完成。

更新：2026-10-28。首版仅 macOS / Apple Silicon，Swift 原生界面 + Rust 内核。当前已实现文件工作台与基础文本编辑、静默构建及后台测试，窗口与性能仍未验证；以下长期阶段尚未全部完成，不作工期承诺。

所有阶段的测试只能静默执行，不得打断用户工作，遵循[开发约定](DEVELOPMENT.md)。下列真实窗口、IME、焦点与输入验收目标保留，但当前不启动 GUI 或操作桌面取得证据；无法静默完成的部分明确标为未验证，不据后台结果宣称该阶段全部验收通过。

## 0. 文档与开源基线

项目定名，旧实现已清理。建立 README、文档索引、需求、架构、性能、依赖、能力台账与 ADR，补充 MIT、贡献指南和文档检查，将当前文档基线提交至用户指定的公开仓库。源码公开与应用发布分别记录。

## 0.1 基础文件浏览工作台

按用户要求，先实现 IDEA 风格原生布局：工具栏、项目树、文件临时/固定标签、面包屑、分组项目切换、透明固定占位滚动条、前进后退和可折叠文件信息；目录仅在树内浏览。Rust 只读枚举目录，支持取消、隐藏文件和明确错误；该阶段未接入编辑，后续阶段已新增基础文本编辑，后续已接入 Dart SDK 语义服务。源码、命令与后台证据见[工作台说明](WORKBENCH.md)。当前静默构建和模型/桥接测试通过，真实窗口验收保留未验证。

## 1. 原生编辑原型

已建立 AppKit TextKit 1 + Rust 文本修订原型，项目树单击编辑，默认自动保存及设置开关、手动保存、独立撤销和关闭保护已接入。所有权与增量桥接见 [ADR 0003](adr/0003-text-editing.md)，当前编码与大小边界见[编辑说明](EDITING.md)。Unicode/修订/编码/保存冲突/权限/取消已取得后台测试证据，IME、撤销交互和输入延迟仍待真实窗口验证。

验收：先取得静默后台测试证据；验证 emoji 位置、编辑事务、保存失败、外部修改和取消保护。原生 IME、真实窗口和输入延迟另列未验证，不在用户桌面执行。可静默测量的内存、文本处理和文件加载数据作为后台比较基线，不代替应用启动及可见交互数据。

## 2. macOS 工作台与基础编辑

打开目录、项目树、标签、面包屑、最近记录、位置恢复、编码/换行、文档查找替换和项目搜索。高亮、括号/缩进、折叠和多光标按优先级逐项增加。完善外部修改、草稿、窗口及退出保护。

验收：多文档独立历史，Unicode/正则搜索与导航返回；大目录加载、搜索和语法解析期间仍可输入；任务可取消，旧结果隔离。普通文件、大文件、超长行分别测量，按预算降级。

## 3. 一个语言的语义闭环

Dart/Flutter 首批依赖、诊断、悬浮、补全、定义/引用、格式化和结构已接入，官方分析器临时样本已取得后台证据；真实项目、Pub 网络和原生交互仍未验证，阶段未全部验收。边界见 [Dart/Flutter 工具](DART_FLUTTER.md)。

根据真实使用场景选择首个语言与服务，接通按需启动、增量文档、补全、诊断、悬停、定义/引用和导航历史，再逐个扩展语言。应用实现语言不自动决定首批支持语言。

验收：带依赖项目、未保存缓冲、中文/emoji 位置、过期响应、缺 SDK、离线、崩溃、重启和工作区关闭；服务失败时保留编辑。固定版本与工具链分开记录。

## 4. 项目工具与配套能力

Git 按 2026-10-28 用户提供的 WebStorm 截图完成需求并获确认实施，G1/G2 首批已接入独立提交/日志布局、本地只读差异和历史、完整文件选择提交、真实暂存区、分支与远端链路；准确范围及后台/窗口验证缺口见 [Git 专题](GIT.md)。G3 已接入同文档差异页编辑首批，继续补齐块选择、行标记、Stash 和合并冲突；独立 Shelf、初始化/克隆及高级历史操作为 G4 扩展候选。首批源码和本机 bare remote 测试不等于完整分期、真实认证或性能验收。

终端首批已接入[本地 PTY 与原生多会话/分屏](TERMINAL.md)，真实窗口与性能仍待验收；任务和构建逐项设计，调试与扩展按各自专题推进。Markdown/HTML、图片/PDF 和归档根据需求安排，不以扩展格式数量代替编辑质量。

验收：操作与真实文件/工具一致，失败和取消可恢复；写 Git、执行命令和安装依赖具有明确入口，不将打开项目视为执行授权。事务、资源和依赖通知完整。
