# HyHub 参考与独立项目边界

更新：2026-10-21。HyCode 是独立的公开项目，没有迁入 HyHub 的源码、二进制或数据，也不要求贡献者能访问任何私有仓库。

## 当前边界

首版围绕 macOS、Swift 原生界面与 Rust 内核重新设计。外部项目的原生编辑、工作台、编码保存和文件预览经验可供研究，但每项能力必须在 HyCode 自己实现、测试并记录。

HyHub 是独立私有项目。可读取其源码不表示可以重新许可或公开；迁入前核对版权、授权、第三方依赖及通知。不能从安装包提取私有二进制替代公开源码，不能迁入凭据、私人样本或用户数据。

## 系列品牌参考

本轮按用户明确要求只读查看 HyHub 的应用图标与图标说明，用其圆角底板、厚笔画和浅立体材质作为系列参考。HyCode 的代码符号图形另由内置 imagegen 创作，原图、私有源码和脚本不迁入本仓库；新图稿与公开资源见[品牌说明](BRANDING.md)。本次没有修改 HyHub 的应用包、源码或用户数据。

## 独立开发要求

- HyCode 的源码、构建、数据、版本和发布独立维护。
- 不依赖账号、设备互访、NAS、远控、云盘或私有服务。
- 不修改 HyHub 源码、固定包、用户数据或服务端作为本项目工作的附带步骤。
- 文档、缓冲、事务与工具任务在 HyCode 中重新确定所有者，不能直接叠加外部编辑历史。
- HyHub 或其他项目的兼容性、性能、后台数量和窗口验收均不计入 HyCode 完成度。

过去的源码映射保留在[历史快照](history/2026-10-21-file-viewer/docs/HYHUB_REUSE.md)，不作为公共开发的前提或当前代码地图。新组件统一按[依赖与来源](DEPENDENCIES.md)登记，许可和性能通过后再决定采用。
