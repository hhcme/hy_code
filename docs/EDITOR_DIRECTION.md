# HyCode 方向与已定事项

更新：2026-10-23。正式名称 **HyCode**，本页记录当前产品边界。历史文件浏览器规划仅供追溯。

## 用户已确认

1. 名称为 HyCode，删除旧实现后从零重写。
2. 开发高性能、轻量、原生的代码编辑器，借鉴 IDEA 工作台组织和 VSCode 轻量体验。
3. **首版仅 macOS**；现有 CPU 范围为 Apple Silicon。
4. **使用 Swift 开发原生界面，Rust 作为内核。**
5. **完全开源**，允许使用合适的官方及社区开源内核、库和语言服务。
6. 公开仓库为 [hhcme/hy_code](https://github.com/hhcme/hy_code)，已建立并推送开源文档基线。
7. **测试只能静默执行，不得打断用户工作。** 不能通过启动应用、窗口、模拟器或操作桌面补齐验收，未执行部分如实标为未验证。
8. 先实现 IDEA 风格基础界面、布局与文件列表浏览，随后接入基础文本编辑；初期分析器和工具服务暂缓，仅提供空入口。后续已接入 Dart/Flutter 首批依赖、分析、问题与结构，Git、终端和搜索仍待实现；Flutter 运行/调试已有首批入口，完整范围见后文。
9. 界面进一步按用户提供截图及本机 WebStorm 的 Islands 风格调整，采用纯色背景、双侧工具条、圆角面板、中央内容之外四区独立显隐和可分栏底行；默认展开左上文件列表与右上 Codex，工具按钮可长按跨角拖放及组内排序；不以后台构建宣称真实视觉已经一致。

10. 目录只在左侧项目树展开和选择，不在中央生成目录列表或目录标签；项目切换参照截图的徽标、名称/路径及打开/最近项目分组；全局滚动条使用细滑块、透明轨道和固定占位。项目树名称不使用省略号，计入层级缩进与完整名称确定列宽，允许横向滚动；根名称不追加完整磁盘路径。

11. HyCode 与 HyHub 属于同系列产品，图标可参考其视觉气质，但 HyCode 标识应明确体现代码编辑器用途；当前新图稿及资源见[品牌说明](BRANDING.md)。

12. 可操作入口应有清晰的鼠标悬停与按下反馈；未打开项目时，中央显示 HyCode 自己的最近项目列表，点击才打开，与项目切换面板保持一致。

13. 启动默认恢复上次打开的项目；无历史或用户已明确关闭项目时显示欢迎页。恢复遵守访问权限，不自动弹出授权或目录选择窗口。

14. 项目树单击文件打开编辑，默认自动保存，并在设置提供可持久化的开关；手动保存、未保存提示与关闭保护保持可用，详见[编辑说明](EDITING.md)。

15. 行号和基础多语言高亮先行，语义能力按 Dart/Flutter、Web、Rust、C/C++ 逐步支持，向 IDEA 的诊断、补全、引用/定义、重构和项目工具交互靠近；各语言/功能独立验收，不把高亮当作语义分析完成。当前范围见[高亮说明](SYNTAX.md)。

16. 2026-10-22 确认 Dart/Flutter 的完整开发能力都需要补齐。九类范围和每项当前缺口见[完整能力清单](FLUTTER_PLAN.md)，允许按依赖顺序分批实现；原生编辑器首版平台与静默测试约束保持适用。

17. 2026-10-23 确认图片直接只读预览，支持缩放和多种格式，暂不编辑；当前基础位图与受限 SVG 范围见[图片预览](IMAGE_PREVIEW.md)。

18. 2026-10-23 确认增加简单本地视频只读预览；默认暂停、基础播放/进度/音量与切标签暂停，当前范围见[视频预览](VIDEO_PREVIEW.md)。

19. 2026-10-23 确认接入 JSON、YAML 等常用配置格式的语法检查、格式化与常用编辑工具；首批 JSON/JSONC、YAML/YML，范围与后续格式见[配置工具](CONFIGURATION_TOOLS.md)。

20. 2026-10-23 确认扩展 Java、SQL、Swift，并增加 Markdown/HTML 左右预览；完整目标见[语言扩展](LANGUAGE_EXPANSION_PLAN.md)，当前分屏实现见[预览说明](MARKUP_PREVIEW.md)。

21. 2026-10-26 确认内置 Codex，默认右侧专用图标和多对话；HyCode 项目使用自定义服务商，系统 CLI/官方 App 保持原官方配置。当前实现、并发/文档保护与验证缺口见[内置 Codex](CODEX_AGENT.md)。

22. 同日确认当前项目直接使用 DeepSeek，思考强度和上下文可调，默认采用模型上限。已接入 V4 Pro/Flash 预设、max、1M 与各对话覆盖；凭据起初使用独立 Keychain，2026-10-28 用户明确改为 HyCode 自管本地文件、不使用系统钥匙串；真实服务与窗口状态分开记录。

23. 2026-10-26 用户明确要求 Codex 面板界面效果对齐 VS Code 的 Codex 插件；采用紧凑头部、按需历史、圆角一体输入和菜单式模型/思考/权限。补齐 HyCode 自有默认服务继承，保留项目显式设置；静默边界不变，实际视觉另验。

24. 2026-10-28 用户明确要求 API Key 等凭据由 HyCode 自己管理，不使用系统钥匙串或系统密码授权；使用应用专用本地目录，与项目源码和系统 Codex 配置分开，见[内置 Codex](CODEX_AGENT.md)。

## 产品基线

2026-10-22 用户要求 Web 相关能力全部纳入。语言、编辑与导航、依赖/脚本、质量、运行/调试和框架适配见 [Web 能力清单](WEB_TOOLS.md)；首批语言服务已接入，不等于全部 WebStorm 功能完成。

代码编辑与项目工作区是主线。工作台包含最近项目、打开文件/目录、项目树、多标签、面包屑、可折叠工具窗口和状态栏；保留 macOS 原生输入法、菜单、快捷键、窗口与无障碍。

桌面工作区默认使用用户明确选择的原位置文件或目录，保存到已授权目标。显式导入副本可另行设计，不强制复制整个项目入库。

高性能通过启动、输入和滚动延迟、内存、文件加载和大项目搜索的实际测量验收，参见[性能设计](PERFORMANCE.md)。使用 Rust 或原生 UI 本身不等于性能已达标。

原生界面、Rust 内核、桥接、构建及文档全部纳入公开源码，采用根 [MIT License](../LICENSE)；第三方组件遵循各自许可，不依赖私有编辑内核、账号或后台。MIT 是本次仓库基础整理采用的项目许可，第三方许可另行登记。

## 架构建议与待决事项

当前工作台采用 SwiftUI、项目树采用 AppKit NSOutlineView，Rust 目录读取通过窄 C ABI 接入，见 [ADR 0002](adr/0002-file-workbench.md)。基础编辑采用 AppKit TextKit 1，Rust 管理正式文本/修订，原生 UndoManager 独占撤销历史，见 [ADR 0003](adr/0003-text-editing.md)。行号和 Tree-sitter 增量着色见 [ADR 0004](adr/0004-line-numbers-syntax.md)；Dart SDK 语义与 Pub 已采用，见 [ADR 0005](adr/0005-dart-tooling.md)；Swift SourceKit-LSP、Java JDT LS 与离线 SQL 已接入，见[ADR 0012](adr/0012-native-languages.md)；Ropey 尚未采用。原方向见 [ADR 0001](adr/0001-macos-swift-rust.md)。

尚待评审：首批目标用户和支持语言、首个可交付版本范围、高级编辑与大文件方案、旧系统运行覆盖、具体性能预算、主题/快捷键及应用分发方式。当前工程的工具链、部署目标和 Bundle ID 已记录在 ADR 0002，不代表完整编辑或发布方案已完成。

## 范围边界

Windows、Linux 和移动端不在首版范围，不设同步工程、兼容门槛或交付承诺；将来需要时另行立项。Swift/Rust 是产品实现语言，不限定用户可编辑的语言。

图片只读预览已接入，采用 ImageIO 与受限 resvg，见 [ADR 0008](adr/0008-image-preview.md)；Markdown/HTML 静态分屏预览已接入，见[预览说明](MARKUP_PREVIEW.md)；PDF 和归档继续分阶段评估。账号、同步、远控、云端转换及兼容 VSCode/IDEA 插件尚未列为首版要求。

## build 40：GB 级文本

用户确认经常处理超过 1 GB 的文本；采用 Rust 磁盘 piece table、原生有界页、独占跨页历史和后台整文件查找/完整原子保存。所有扩展名共享大小/长行路由，局部页不得用于全文 LSP 修改。范围、资源预算、真实 GB 后台样本与连续滚动/全局行号/窗口性能缺口见[大文件专题](LARGE_FILES.md)和[ADR 0013](adr/0013-disk-backed-text.md)。
