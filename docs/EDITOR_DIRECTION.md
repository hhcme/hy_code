# HyCode 方向与已定事项

更新：2026-10-21。正式名称 **HyCode**，本页记录当前产品边界。历史文件浏览器规划仅供追溯。

## 用户已确认

1. 名称为 HyCode，删除旧实现后从零重写。
2. 开发高性能、轻量、原生的代码编辑器，借鉴 IDEA 工作台组织和 VSCode 轻量体验。
3. **首版仅 macOS**；现有 CPU 范围为 Apple Silicon。
4. **使用 Swift 开发原生界面，Rust 作为内核。**
5. **完全开源**，允许使用合适的官方及社区开源内核、库和语言服务。
6. 公开仓库为 [hhcme/hy_code](https://github.com/hhcme/hy_code)；本次先整理文档结构并提交推送，不开始应用实现。

## 产品基线

代码编辑与项目工作区是主线。工作台包含最近项目、打开文件/目录、项目树、多标签、面包屑、可折叠工具窗口和状态栏；保留 macOS 原生输入法、菜单、快捷键、窗口与无障碍。

桌面工作区默认使用用户明确选择的原位置文件或目录，保存到已授权目标。显式导入副本可另行设计，不强制复制整个项目入库。

高性能通过启动、输入和滚动延迟、内存、文件加载和大项目搜索的实际测量验收，参见[性能设计](PERFORMANCE.md)。使用 Rust 或原生 UI 本身不等于性能已达标。

原生界面、Rust 内核、桥接、构建及文档全部纳入公开源码，采用根 [MIT License](../LICENSE)；第三方组件遵循各自许可，不依赖私有编辑内核、账号或后台。MIT 是本次仓库基础整理采用的项目许可，第三方许可另行登记。

## 架构建议与待决事项

SwiftUI 组织工作台、AppKit 承担编辑交互是候选组合；文本缓冲、撤销历史的具体归属与 Swift/Rust 增量桥接先做原型。Ropey、Tree-sitter、SourceKit-LSP 等属于候选，不代表已经采用。确认事项见 [ADR 0001](adr/0001-macos-swift-rust.md)。

尚待评审：首批目标用户和支持语言、首个可交付版本范围、最低 macOS、Swift/Rust 与绑定工具版本、编辑视图实现、具体性能预算、主题/快捷键、Bundle ID 与应用分发方式。

## 范围边界

Windows、Linux 和移动端不在首版范围，不设同步工程、兼容门槛或交付承诺；将来需要时另行立项。Swift/Rust 是产品实现语言，不限定用户可编辑的语言。

Markdown/HTML、图片/PDF 和归档等配套能力在编辑主线后评估。账号、同步、远控、云端转换及兼容 VSCode/IDEA 插件尚未列为首版要求。

## 当前状态

旧应用、核心、绑定、构建入口和测试已删除；现在只有文档与文档检查工具，没有可运行应用。原源码仍在 Git 历史中，详见[重写记录](REWRITE_RECORD.md)。后续工程和发布身份围绕 HyCode 新建，不沿用旧产品标识。
