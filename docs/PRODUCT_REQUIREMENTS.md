# HyCode 产品需求

更新：2026-10-21。本页为长期需求基线；当前已实现文件工作台与基础文本编辑，具体范围与验证见[工作台说明](WORKBENCH.md)和[编辑说明](EDITING.md)，不能把以下目标全部视为已完成。首版仅 macOS / Apple Silicon、Swift 原生界面 + Rust 内核；首批语言与可交付版本范围仍待评审。

## 首版边界与质量目标

首版专注高性能 macOS 代码编辑器。原生界面、内核、桥接和构建完全开源；可以复用许可适用的官方与社区组件。Swift/Rust 是实现语言，不自动决定编辑器只支持这两种语言。

启动、文件加载、输入与滚动、搜索、内存及取消恢复属于验收内容，按[性能设计](PERFORMANCE.md)建立样本和预算。解析、扫描、索引或语言服务忙碌时，编辑区域仍应保持响应。其他平台不纳入首版交付；Git、终端、调试和配套预览的顺序见路线，不能把全部长期目标视为首个版本的承诺。

## 使用场景

- 快速打开单个文本/代码文件，编辑、搜索并安全保存。
- 打开项目目录，在项目树、符号、定义/引用、搜索结果间导航，保留编辑位置。
- 按需启用语言服务、Git、终端和运行任务，保持基础编辑可用与界面响应。
- 在编辑流程中预览 Markdown/HTML、图片、PDF 或归档内容，不丢失当前工作区位置。

## 工作区与文件所有权

桌面默认通过用户选择打开原位置文件或目录。打开目录不复制整个项目；保存作用于清晰显示的已授权原文件。显式“导入副本”需与原位置模式区分，不能静默切换保存目标。

单文件与项目工作区分开建模；打开一个源码文件不等于已获得父目录、依赖、SDK 或 `.git` 的完整访问。支持多目录工作区作为后续方向，不要求首个骨架同时实现。最近项目/文件记录路径或平台访问标记，不把最近项当作永久权限。

监听外部修改、移动、删除、权限失效与链接变化。打开失败提供原地重试或重新定位；重载与保存冲突保留缓冲，让用户选择。工作区状态包括打开标签、活动文件、光标、选择、滚动、目录展开和工具窗口布局。

## 工作台交互

| 区域 | 设计基线 |
| --- | --- |
| 首页 | 最近项目/文件、打开文件、打开目录和继续工作；不以空白文件库作为主入口 |
| 项目树 | 展开目录、按需加载、文件类型图标、筛选和常用整理操作；大目录扫描可取消；选择目录不生成中央目录表格或标签 |
| 编辑标签 | 仅文件创建标签，紧凑单行、文件图标、同名路径区分、活动态和脏标记；支持关闭与标签导航 |
| 面包屑 | 展示工作区相对路径，明确当前文件来源；父目录、路径复制与定位操作可发现 |
| 工具窗口 | 项目、搜索、结构、Git 等侧边区域，以及终端/任务/诊断等底部区域，可折叠和调整尺寸 |
| 内容预览 | 快速预览保留项目树、搜索结果和原编辑位置；持续阅读固定为标签；独立窗口后续评估 |
| 状态栏 | 文件类型、编码、换行、光标位置、只读/保存/工具状态，显示实际状态而非虚构进度 |

参考 IDEA 的布局组织和视觉层级，保持 macOS 原生输入、菜单及系统行为。具体尺寸、动效和主题由原型测量决定，支持减少动态效果、键盘导航和无障碍。

工具窗口展开/折叠应有连续的位移与尺寸动画，相邻区域同步补位；重新展开保留用户调整的尺寸、树展开及滚动状态。隐藏区域不接受焦点与命中，减少动态效果开启时取消位移动画。窗口内四边、工具条和分块间隙采用统一的纯色外框，不使用渐变背景。中央内容之外左上、右上、左下、右下工具区域可独立显隐，底部两块可分栏并调整比例；单块展开时填满底行。相邻边界按同一显示像素网格取整，拖动不触发全工作台观察状态更新。默认仅展开左上文件列表，其他工具面板隐藏；各角支持多个工具入口，单角显示一个活动工具。工具按钮长按后可拖到任一角落或在组内调整顺序；提供菜单移动和排序作为键盘替代。新增工具先提供空白内容，不启动对应服务。分隔高亮线缩进圆角范围，仅在悬停或拖动时显示强调色，鼠标移出后清除。工具拖拽预览保留按钮的纯色底、圆角、图标尺寸和明确前景色，深色区域中也可识别；不同显示缩放下生成对应像素密度，不直接使用无底色的模板符号。

项目切换使用分组面板：徽标、项目名和完整路径分两行显示，区分已打开和最近项目；不以路径菜单替代。当前只存在一个打开的项目，最近项来自 HyCode 自己的打开历史，不导入其他应用记录。启动默认恢复上次打开的项目；展示其他最近项不解析其书签或读取目录。访问书签在后台以无 UI、无自动挂载选项解析；失败时保留目录读取错误与重试，不自动弹出选择窗口。用户明确关闭项目后下次保留欢迎页，关闭不删除历史；后续打开会更新启动项目。旧版只有历史时迁移首项，迁移后单独记录启动项目，不以历史首项长期代替会话状态。

左上角项目入口在无项目时显示“打开项目”；打开目录后，标题、徽标和“打开的项目”行共用当前目录身份，路径标准化后区分最近项。“最近的项目”不包含当前已打开项目；历史首项不代表当前会话。下拉面板顶部按新建、打开、克隆排列操作；尚未实现的新建/克隆明确置灰。项目列表随条目数量收缩，超过最大高度后滚动。

未打开项目时，中央欢迎页展示同一份最近项目，可整行点击继续工作，窄窗口和小高度下仍可滚动访问。打开项目后若没有文件标签，中央保持空白，不生成目录列表。按钮、菜单入口、标签及可点击项目行提供可见的悬停、按下和焦点反馈；选中态仍能分辨悬停和按下，禁用入口不显示可点击反馈。反馈不改变控件尺寸或触发扫描。

应用内滚动条统一透明轨道、细滑块和固定占位，不因内容变长或系统自动隐藏设置突然挤占可见区域。当前纵向保留 8 pt 槽、滑块绘制 4 pt；项目树横向也固定保留 8 pt 槽，名称与缩进决定内容列宽，文件/目录名不使用省略号，溢出可横向滚动。横向标签和面包屑持续隐藏滚动条，不动态挤占布局。项目树的悬停与选中使用一致的可见整行和轻微圆角，目录层级只缩进内容；横向滚动后仍保留两端圆角，悬停色弱于选中色。列表左右留白对称：当前左侧 12 pt、右侧 4 pt 加 8 pt 纵向槽；底部额外留白 8 pt，让固定横向槽处于列表内部并避开面板圆角。固定滚动槽保持透明，底带与列表使用同一纯色。像素效果仍需窗口验收。

当前项目树根行只显示项目名称，完整磁盘路径放到目录/文件悬浮提示与信息面板。右键菜单以点中条目为目标，支持打开/展开折叠、复制完整或相对路径、在访达显示、查看信息和刷新；未实现的文件改写操作不作为可用菜单项。两条滚动槽交叉处没有独立业务入口，不显示有边框的小方块。

## 编辑与保存

项目树单击文件即进入编辑，修改后固定临时标签；默认停止输入 800 ms 后自动保存，设置提供持久化开关，关闭后使用 ⌘S 或全部保存。组合输入期间暂缓自动保存，失败明确提示且不反复自动重试。当前编码、大小及未实现项见[编辑说明](EDITING.md)。

文本默认进入编辑模式；只读、权限不足、二进制或资源预算不适用时明确说明。基础能力包括原生输入法、选择/剪贴板、行号、缩进、独立撤销重做、查找替换、编码/BOM/换行保留；增量高亮、括号、折叠、多光标分阶段增加。

查找采用悬浮面板，支持下一项/上一项、计数、大小写、整词、正则和替换。编辑器查找与整个项目搜索区分；搜索结果打开目标并记录回退位置。重命名、格式化和跨文件替换通过统一事务管理，不绕过脏缓冲。

保存先检查文件版本与权限，再按平台完成安全写入；失败保留缓冲和草稿。关闭有未保存更改的标签提供“保存 / 丢弃更改 / 取消”；保存失败或冲突不关标签。关闭窗口、退出、切换工作区与恢复草稿复用该保护，不能只处理标签按钮。

## 代码智能及工具

2026-10-22 用户已明确要求补齐完整 Dart/Flutter 开发能力。设备/运行配置、运行/构建、调试、热更新、测试/覆盖率、Inspector/DevTools、智能编辑、快速修复/重构、项目/多 SDK/依赖九类全部纳入，按[完整能力清单](FLUTTER_PLAN.md)逐项实现与验收；当前实现和未验证状态不能据此改为完成。

当前行号与基础多语言着色见[高亮说明](SYNTAX.md)。当前已接通 Dart/Flutter 首批诊断、悬浮、补全、定义/引用、格式化和问题/结构面板及 Pub 依赖，范围见 [Dart/Flutter 工具](DART_FLUTTER.md)；后续扩展 Web、Rust、C/C++；调用/继承层级、重命名和快速修复逐项验收。Flutter 运行、调试、热重载和 Inspector 独立接入，不由语言着色自动获得。

高亮和结构解析与语义服务分层。通过可验证的语言服务接入补全、悬停、诊断、定义/实现跳转、引用和重命名；按工作区/语言启动，旧响应不覆盖新文档。先用一个语言验证全链路，再扩语言清单。

Git、差异、终端、任务、构建和调试属于后续主线，分别建立交互与取消/错误语义。扩展接口可规划，不预设兼容 VSCode Marketplace、VSIX 或 IDEA 插件。查看项目不自动等于允许运行构建脚本、项目插件或安装依赖。

## 配套能力与范围

Markdown/HTML 源码与排版预览、常见图片/PDF/系统兜底预览，以及压缩包浏览/解压/创建作为独立阶段。各格式、读写、加密、平台和资源限制分别验收，不把全部候选扩展名列为已支持。可视化 Office 编辑、CAD 创作、数据库写入和云端转换不是首版承诺。

HyHub 的账号、设备互访、NAS、远控与其发布设施不自动纳入 HyCode。基础编辑面向本地离线使用；需要网络的可选下载、远程内容或服务另行定义。
