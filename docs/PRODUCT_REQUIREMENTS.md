# HyCode 产品需求

更新：2026-10-21。当前没有应用实现，以下功能均为重写目标。用户确认的方向见[方向记录](EDITOR_DIRECTION.md)；首版只面向 macOS / Apple Silicon，Swift 原生界面 + Rust 内核。本页细节为需求基线，首批语言和首个可交付版本范围仍待评审。

## 首版边界与质量目标

首版专注高性能 macOS 代码编辑器。原生界面、内核、桥接和构建完全开源；可以复用许可适用的官方与社区组件。Swift/Rust 是实现语言，不自动决定编辑器只支持这两种语言。

启动、文件加载、输入与滚动、搜索、内存及取消恢复属于验收内容，按[性能设计](PERFORMANCE.md)建立样本和预算。解析、扫描、索引或语言服务忙碌时，编辑区域仍应保持响应。其他平台不纳入首版交付；Git、终端、调试和配套预览的顺序见路线，不能把全部长期目标视为首个版本的承诺。

## 使用场景

- 快速打开单个文本/代码文件，编辑、搜索并安全保存。
- 打开项目目录，在项目树、符号、定义/引用、搜索结果间导航，保留编辑位置。
- 按需启用语言服务、Git、终端和运行任务，保持基础编辑可用与界面响应。
- 在编辑流程中预览 Markdown/HTML、图片、PDF 或归档内容，不丢失当前工作区位置。

## 工作区与文件所有权

桌面默认通过用户选择打开原位置文件或目录。打开目录不复制整个项目；保存作用于清晰显示的已授权原文件。显式“导入副本”需与原位置模式区分，不能静默切换保存目标。

单文件与项目工作区分开建模；打开一个源码文件不等于已获得父目录、依赖、SDK 或 `.git` 的完整访问。支持多目录工作区作为后续方向，不要求首个骨架同时实现。最近项目/文件记录路径或平台访问标记，不把最近项当作永久权限。

监听外部修改、移动、删除、权限失效与链接变化。打开失败提供原地重试或重新定位；重载与保存冲突保留缓冲，让用户选择。工作区状态包括打开标签、活动文件、光标、选择、滚动、目录展开和工具窗口布局。

## 工作台交互

| 区域 | 设计基线 |
| --- | --- |
| 首页 | 最近项目/文件、打开文件、打开目录和继续工作；不以空白文件库作为主入口 |
| 项目树 | 展开目录、按需加载、文件类型图标、筛选和常用整理操作；大目录扫描可取消 |
| 编辑标签 | 紧凑单行、文件图标、同名路径区分、活动态和脏标记；支持关闭与标签导航 |
| 面包屑 | 展示工作区相对路径，明确当前文件来源；父目录、路径复制与定位操作可发现 |
| 工具窗口 | 项目、搜索、结构、Git 等侧边区域，以及终端/任务/诊断等底部区域，可折叠和调整尺寸 |
| 内容预览 | 快速预览保留项目树、搜索结果和原编辑位置；持续阅读固定为标签；独立窗口后续评估 |
| 状态栏 | 文件类型、编码、换行、光标位置、只读/保存/工具状态，显示实际状态而非虚构进度 |

参考 IDEA 的布局组织和视觉层级，保持 macOS 原生输入、菜单及系统行为。具体尺寸、动效和主题由原型测量决定，支持减少动态效果、键盘导航和无障碍。

## 编辑与保存

文本默认进入编辑模式；只读、权限不足、二进制或资源预算不适用时明确说明。基础能力包括原生输入法、选择/剪贴板、行号、缩进、独立撤销重做、查找替换、编码/BOM/换行保留；增量高亮、括号、折叠、多光标分阶段增加。

查找采用悬浮面板，支持下一项/上一项、计数、大小写、整词、正则和替换。编辑器查找与整个项目搜索区分；搜索结果打开目标并记录回退位置。重命名、格式化和跨文件替换通过统一事务管理，不绕过脏缓冲。

保存先检查文件版本与权限，再按平台完成安全写入；失败保留缓冲和草稿。关闭有未保存更改的标签提供“保存 / 丢弃更改 / 取消”；保存失败或冲突不关标签。关闭窗口、退出、切换工作区与恢复草稿复用该保护，不能只处理标签按钮。

## 代码智能及工具

高亮和结构解析与语义服务分层。通过可验证的语言服务接入补全、悬停、诊断、定义/实现跳转、引用和重命名；按工作区/语言启动，旧响应不覆盖新文档。先用一个语言验证全链路，再扩语言清单。

Git、差异、终端、任务、构建和调试属于后续主线，分别建立交互与取消/错误语义。扩展接口可规划，不预设兼容 VSCode Marketplace、VSIX 或 IDEA 插件。查看项目不自动等于允许运行构建脚本、项目插件或安装依赖。

## 配套能力与范围

Markdown/HTML 源码与排版预览、常见图片/PDF/系统兜底预览，以及压缩包浏览/解压/创建作为独立阶段。各格式、读写、加密、平台和资源限制分别验收，不把全部候选扩展名列为已支持。可视化 Office 编辑、CAD 创作、数据库写入和云端转换不是首版承诺。

HyHub 的账号、设备互访、NAS、远控与其发布设施不自动纳入 HyCode。基础编辑面向本地离线使用；需要网络的可选下载、远程内容或服务另行定义。
