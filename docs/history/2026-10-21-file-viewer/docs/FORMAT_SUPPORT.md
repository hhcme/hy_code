## 1. 状态与操作定义

- **已有代码**：本仓存在对应实现，可定位入口；不自动代表本轮验证通过。
- **历史验证记录**：注明日期、平台、样本及证据范围。本次只核对代码，没有重新运行。
- **规划**：产品目标或候选方案，尚未实现/验证，不能对外标为支持。
- **受限/不适用**：明确格式、引擎、平台或操作的限制，不能用扩展名一概判断。

操作分列：识别、列目录/结构、内容预览、搜索/交互、提取/导出、创建、编辑/保存、加密/分卷。某项通过不推导其他项通过，例如 RAR 解压不推导 RAR 创建，Office 预览不推导无损编辑。

## 2. 当前可定位实现

| 能力 | 平台与入口 | 本仓状态 | 证据与限制 |
| --- | --- | --- | --- |
| ZIP 选择与导入 | macOS `App/HcFileViewer/HomeView.swift` | 已有代码 | 当前选择器只允许 ZIP，单文件 |
| 复制入库、来源及最近记录 | `packages/HcCoreSwift/Sources/HcLibrary/LibraryStore.swift` | 已有代码 | JSON 持久化；复制/读写尚需后台化；无目录/标签数据库 |
| ZIP 目录读取 | `core/src/lib.rs` 的 `ZipReader` | 已有代码 | 当前 zip 依赖启用 deflate；一次返回全量条目，非最终分页实现 |
| ZIP 条目展示 | `App/HcFileViewer/ArchiveView.swift` | 已有代码 | 平面条目列表，尚无提取、预览和创建 |
| UTF-8 中文名及基础错误用例 | Rust 测试与 Swift `HcCoreTests` | 有测试源码及 2026-10-19 历史通过记录 | 选定合成样本，不等于各种旧编码、损坏、加密或大包兼容；本轮未重跑 |
| 其他平台与编辑/预览引擎 | 无 | 规划 | SwiftUI 骨架、绑定可生成不等于其他端已完成 |

ZIP64、大包、密码/分卷、非 UTF-8 名字与损坏恢复未在本仓形成验收记录；不得沿用 HyHub 的大样本结论。

## 3. 产品目标矩阵

下表全部为后续目标；当前实现仅以上节为准。具体引擎按平台、许可、体积、性能和样本确定。

| 类别 | 格式候选 | 目标操作 | 当前边界 |
| --- | --- | --- | --- |
| 文本与代码 | TXT、LOG、常见源码、INI | 浏览、搜索、高亮、编辑、保存 | 尚未实现；补全/语义见[代码智能](CODE_INTELLIGENCE.md) |
| 网页与标记 | HTML/HTM、Markdown、MHT/MHTML | 排版预览、源码编辑、相对资源与目录 | MHTML 单独评估；不默认执行脚本/远程请求 |
| 配置/数据 | JSON/JSONC、XML、YAML、TOML、CSV/TSV、JSONL | 文本与结构视图、校验、逐步增加编辑 | 不把格式化等同于无损保留注释/顺序/编码 |
| PDF/办公 | PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX、RTF、ODF、Apple 办公格式、XPS | 分页/工作表/幻灯片预览、搜索/导出按引擎能力 | 可视化编辑、批注、宏与公式重算不自动纳入 |
| 电子书/漫画 | EPUB、MOBI、AZW3、FB2、CBZ/CBR | 目录、阅读进度、重排/翻页 | DRM 内容不直接承诺 |
| 图片 | JPEG、PNG、GIF、HEIC、WebP、BMP、TIFF、SVG、AVIF、ICO、部分 RAW | 缩放、动画/多页、元信息 | RAW 子类、色彩、超大图及图像编辑分别验证 |
| 音视频/字幕 | MP3、AAC、WAV、FLAC、OGG、MP4、MOV、MKV、AVI、WebM、SRT/ASS/VTT | 播放、定位、字幕及元数据 | 容器不等于内部编码；逐端验证硬解、样式及功耗 |
| 压缩/归档 | ZIP、RAR、7z、TAR、GZ、BZ2、XZ、ZST、CAB、复合归档 | 列目录、按需预览、解压；ZIP/7z 等创建候选 | 当前只有 ZIP 目录；每格式读/写/密码/分卷分开 |
| 镜像/安装容器 | 部分 ISO、APK、IPA；DMG 候选 | 浏览内容与元信息、按需提取 | 不运行或安装容器内应用 |
| 数据库 | SQLite | 表/记录只读浏览，其他操作另定 | `.db` 不一定是 SQLite；不默认迁移或写数据库 |
| 邮件/资料 | EML、MSG、VCF、ICS | 正文、附件、结构信息 | 不默认导入系统通讯录/日历或加载远程资源 |
| 字体 | TTF、OTF、WOFF/WOFF2 | 字形、样例和字体信息 | 不自动安装系统字体 |
| 设计/出版 | PSD、AI、EPS、CDR、DjVu、CAJ | 合成图/页面/内容，视引擎能力 | 缩略图、完整图层、无损编辑分开；专业 SDK 另评估 |
| 图纸/三维 | DWG/DXF、STL、OBJ、GLB/glTF、USDZ、STEP/IGES | 图纸/模型、视图、单位与元数据 | 外部引用、材质、版本、模型规模及许可逐项验证 |

## 4. 单条兼容性记录模板

每新增一项，至少记录：

| 字段 | 内容 |
| --- | --- |
| 身份 | 类别、格式版本/变体、容器与编码、识别依据 |
| 实现 | 模块/引擎、锁定版本、平台原生/共享 Rust 路径、许可及通知 |
| 平台 | OS 版本、架构、设备/模拟器、构建渠道与权限 |
| 操作 | 哪些操作已实现/验证，哪些只读、降级或不支持 |
| 样本 | 可分发来源/生成方法、文件大小/哈希、页数/条目数、密码/损坏/名字编码等特征 |
| 检查 | 命令、输入与输出摘要、回归日期、后台与交互证据分别记录 |
| 资源 | 首屏/耗时、峰值内存、临时空间、取消和失败恢复，测量方式明确 |
| 限制 | 格式/平台限制与工作预算，超出时的降级，不用无依据的“全部支持” |

手机受内存与后台生命周期约束，工作预算可与桌面不同。普通归档不设任意固定大小上限，不等于无限内存、无限磁盘或无限解压膨胀；使用流式 I/O 和资源保护，遇到不适用条件给出可理解的错误。
