# HyCode 能力与格式台账

更新：2026-10-21。**当前所有应用能力均未实现**，仅有项目文档与文档检查工具。首版仅 macOS / Apple Silicon、Swift 原生界面 + Rust 内核。旧 ZIP 骨架已删除，历史测试与外部项目的兼容记录不能作为当前支持依据。

## 状态规则

“规划”表示目标；“已实现”需有本仓入口；“已验证”另需注明平台、版本、命令和证据；构建、后台、真实窗口、签名打包和发布分别记录。只通过一个格式/平台/样本，不推导全部变体可用。

测试只能静默执行，不得打断用户工作。需要真实窗口、输入或桌面操作的测试当前不执行并保持未验证，不能删掉验收项或以后台测试代替。执行边界见[开发约定](DEVELOPMENT.md)。

## 配套格式规划

| 类别 | 候选 | 目标与限制 |
| --- | --- | --- |
| 源码/文本/配置 | 常用语言、TXT/LOG、JSON/JSONC、YAML、TOML、XML、CSV/TSV | 文本编辑为主；语义、格式化与结构视图另验 |
| 标记与网页 | Markdown、HTML | 源码编辑与排版预览；本地资源、脚本和网络边界单独设计 |
| 图片与 PDF | 常见图片、SVG、PDF | 只读预览候选，色彩、多页、解码和大文件预算分别验证 |
| 压缩归档 | ZIP、RAR、7z、TAR 及常见压缩流 | 列目录、按需提取；创建按格式分别确定，不从 RAR 读取推导 RAR 创建 |
| 其他文档 | 系统原生预览可覆盖的文件等 | 作为兜底/后续能力，不承诺可编辑或全部版本可用 |

电子书、媒体、Office、数据库、专业设计与 CAD 等广泛类别保留在[历史格式调研](history/2026-10-21-file-viewer/docs/FORMAT_SUPPORT.md)，不是重写首版必须全部实现的清单。

## 每项记录模板

至少包含：格式/语言和操作、引擎及固定版本、源码与依赖许可、平台/架构/渠道、实现入口、可分发样本或生成方法、大小和哈希、执行命令与日期、后台/窗口证据、结果及限制。

性能记录启动/首屏、输入延迟、峰值与空闲内存、扫描/索引、临时磁盘、取消和失败恢复；不使用没有测量依据的“无限大小”或“全部支持”。所有格式和平台目前尚无本次重写验证结果。

## 仓库基础设施

MIT 许可、贡献指南、文档索引、ADR、性能与依赖记录、Issue/PR 模板及文档检查属于仓库基础设施，不计作编辑器功能实现。`python3 scripts/check_docs.py` 检查文档本地链接和历史快照哈希；GitHub `Documentation` 工作流结果另行查看，不等于应用测试。
