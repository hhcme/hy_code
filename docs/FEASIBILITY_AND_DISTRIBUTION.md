# HyCode 开源与分发准备

更新：2026-10-21。首版仅 macOS / Apple Silicon，Swift 原生界面 + Rust 内核。源码入口与应用分发是不同状态。

## 公开源码基线

公开仓库：[hhcme/hy_code](https://github.com/hhcme/hy_code)，默认分支 `main`。本次按用户授权整理并提交推送项目文档；没有创建新应用、发布应用版本或上传安装包。

自有代码和文档采用根 [MIT License](../LICENSE)，标准文本来源见 [Open Source Initiative](https://opensource.org/license/mit)。许可范围包括原生 UI、Rust 内核、桥接、构建脚本及文档；第三方组件保留自身许可与通知。

贡献入口见 [CONTRIBUTING.md](../CONTRIBUTING.md)，安全问题见 [SECURITY.md](../SECURITY.md)。没有额外 CLA、账号或私有后台作为基础开发与编辑前提。

## 当前应用状态

尚无应用源码、构建入口、测试、签名身份、打包产物或下载版本。文档检查和 GitHub Actions 只验证文档；不能据此宣称 macOS 应用可用或性能达标。旧实现保留在 Git 历史，不能作为重写产物发布。

## 应用发布前的准备

- 根据原型固定最低 macOS、Swift/Rust、Xcode、绑定工具及构建配置，提供独立可复现的构建命令。
- 对每个实际引入的库、语法包、语言服务及二进制，记录固定版本、许可、来源、通知与分发方式，见[依赖台账](DEPENDENCIES.md)。
- 用可分发样本完成后台、真实窗口和性能验收，分别保留证据。
- 检查当前内容与待推送历史中的凭据、私人数据、私有代码及生成缓存；不依赖维护者本机路径。历史研究原文明确标注，不构成当前构建前提。
- 决定 macOS 分发渠道、签名、公证或商店方案后再核对实际要求；当前不承诺商店优先或具体日期。
- 发布时分别记录版本、产物哈希、签名检查、上传、处理及公开可获取状态。

## 联网与后续范围

基础编辑、文件访问和搜索面向本地离线使用。下载语言服务、更新和远程内容等网络行为分别设计，不默认上传源码，不自动安装依赖或执行项目脚本。

其他平台、云端服务、商业安排及应用分发渠道均需后续需求评审。本项目完全开源，不将历史付费解锁、商店路线或费用估算直接写为当前产品要求。
