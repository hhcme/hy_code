# ADR 0004：原生可见行号与后台增量高亮

- 状态：采用基础实现；真实窗口与性能未验证
- 日期：2026-10-21
- 范围：首批多语言着色与行号，语言服务另行实现

## 决策

Rust 文档附带 Tree-sitter 缓存，用已有编辑事务更新旧树，按修订和可见范围返回 UTF-16 颜色片段；解析、查询与编码都在文档 actor，语法状态不拥有另一份正式文本。Swift 使用 NSLayoutManager 临时颜色，不修改 NSTextStorage 的正文或撤销历史。

行号采用 NSRulerView，只绘制可见逻辑行。Swift 的分块行起点属于原生输入投影，初始后台构建，输入时局部维护，避免逐次全文扫描。既有 Rust 文本与原生 UndoManager 的唯一所有权不变。

先覆盖 Dart、Web 常用语言及 C/C++、Rust 的语法着色；语义功能的顺序为 Dart/Flutter、Web、Rust、C/C++。Tree-sitter 不作为编译器诊断或跨文件引用服务。Dart/Vue 社区语法独立记录版本、来源与许可证，不复制私有安装包中的资源。

## 约束与后续

当前 1 MiB 高亮、65,536 UTF-16 单位/视口、4,096 条合并结果和 100 ms 解析/捕获协作预算，详细嵌入规则见[高亮说明](../SYNTAX.md)。预算超限仍保留基础编辑与保存。真实 IME、撤销、颜色、软换行、帧率和旧系统需要另验，不以后台测试冒充窗口验收。

下一阶段建立可复用语言服务管理与 Dart 诊断/补全/导航，再扩到其他语言；跨文件修改需统一版本检查、预览和撤销，不能直接改写磁盘绕过文档。
