# ADR 0009：原生只读视频与描述符分段资源

- 状态：已接入，后台验证；真实窗口/播放待验收
- 日期：2026-10-23

## 背景

用户要求简单视频预览，沿用工作台标签和样式。视频可能远大于图片，不能复用整文件图片解码、文本缓冲或自动保存。

## 决策

独立 `VideoPreviewDocument` 拥有播放器和查看状态。首批路由本地 MP4/MOV/M4V，系统 AVFoundation 异步读取属性、解码，`AVPlayerLayer` 呈现画面，自有控件提供播放/暂停、进度、音量和自动适应；默认暂停，切标签卸载播放器并保留进度。Rust 文本/目录内核的所有权保持不变，不为平台播放器新增帧传输 ABI。

使用授权根内固定普通文件描述符及私有 URL 的 AVAssetResourceLoader，按需提供小块范围，禁止外部引用。不将原路径直接交给解码器，不复制或一次性载入整段视频。文件、访问租约、delegate 和请求共同明确释放责任；关闭/切换以代次拒绝旧结果。

定位采用一项在途请求和可覆盖的最新目标，避免拖动产生大量互相取消的 seek。视频帧直接由原生播放层更新；SwiftUI 只低频更新控件。

## 影响与验收

使用 Apple 平台 AVFoundation/CoreMedia/CoreVideo，没有新增第三方依赖。格式、资源限制、测试和未验证项见[视频预览](../VIDEO_PREVIEW.md)。首批无倍速、循环、字幕/多轨选择、网络播放、额外容器或视频编辑。

静默测试只创建无音轨小样本，检查元数据/单帧及模型，不实例化播放器或 GUI。真实首帧、声音、播放/暂停、拖动、切标签、辅助功能、旧系统和性能仍保留为未验证。
