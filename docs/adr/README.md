## 新建方式

使用 `NNNN-short-name.md`，按顺序编号。包含：状态、日期、背景、决策、理由、影响、未决定事项，以及验收条件或关联文档。候选使用“提议”，接受后记录证据；被取代的决策保留并链接后继。

基础文本与撤销归属、原生视图和增量桥接见 ADR 0003。接下来需验证的主题包括：实际 IME/撤销交互、语言服务、大文件与性能预算。工具链和部署目标见 ADR 0002；后台测试不替代窗口验收。
