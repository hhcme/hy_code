# ADR 0015：原生本地交互终端

日期：2026-10-28。状态：已采用，后台/窗口验收分别记录。

## 决策

1. 采用固定 SwiftTerm 1.20.0 的模拟器/AppKit 视图，使用 HyCode 自有标题、标签、菜单、查找和设置，不采用 JVM 或 WebView 工作台。
2. 项目终端控制器独占标签/分屏会话，单分屏独占屏幕与 PTY；隐藏只影响显示与焦点，关闭须确认并等待进程回收。
3. C `posix_spawn` + 随包 C helper 在新进程获得 session/control tty/job control，再 exec 用户 Shell；不在已有 Swift 进程 fork 后执行 Swift。所有原生 FD/信号/等待在单会话 utility 队列，界面以有界输出消费提供背压。
4. 人工 Shell 保持用户配置及传统按键行为，不接管成“输入整行后提交”的假终端。Codex 私有运行配置与凭据独立；活动终端阻止 Agent 修改租约，只读对话仍可用。
5. 当前只接本地交互；首批 zsh integration 仅报告编辑状态、核对插入与默认提示符配色，候选使用固定元数据和授权目录。跨重启恢复、SSH、完整动态 CLI 语义和任务控制台迁移分别评估。不从终端输出获得文件访问权限，也不把工作目录当作系统沙箱。

## 验收与影响

依赖与许可由 `Package.resolved`、终端台账及离线脚本校验。后台使用生成路径、非登录固定命令和真实无 GUI PTY；zsh 中继/候选使用禁用全局启动文件、HOME 与配置均生成的固定样本，登录中继样本也不读取用户配置。模拟器测试只实例化 headless 内核。原生视图仅编译，不能据后台通过宣称窗口、IME、TUI 或性能已验收。当前预算、进程组回收边界、源码地图与尚未实现范围见[终端专题](../TERMINAL.md)。
