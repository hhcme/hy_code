# ADR 0010：固定配置服务、离线 Schema 与原生受限读取

- 状态：已接入，后台验证；真实窗口待验收
- 日期：2026-10-23

## 背景

用户要求 JSON、YAML 的语法检查、格式化与常用工具。既有 JSON 只有基础服务，YAML 只有高亮。配置文件不应因打开或格式化自动下载规则、执行项目 Prettier 配置或建立第二个正式文本缓冲。

## 决策

沿用工作区 `WebLanguageServer` 与原生语义/编辑入口。JSON 使用已固定的 vscode-langservers-extracted 4.10.0，YAML 新增公开 yaml-language-server 2.0.0；自有窄启动适配器注入 Schema reader，并在初始化前关闭在线目录。外部 Node 最低版本仍为 22.22.2，安装禁用 hooks，不分发 Node。

常用清单规则固定 14 个 SchemaStore 原字节及传递引用，记录 commit、来源、SHA-256、原始 Apache-2.0 LICENSE/NOTICE。仅已随包的远程 URI 映射到这些字节；未知网络 URI 拒绝。项目 Schema 的 file URL 经反向请求进入授权根内原生读取，复用逐级 no-follow、大小、编码与取消边界，不由 Node 任意读取磁盘。

连接最多记录 500 个本地依赖（含读取失败），适配器最多 8 个在途请求。保存/磁盘事件按依赖 URI 通知失效；全量重查覆盖已观察的全部路径，不能只看当前扫描文件。监听传递安全路径下的任意文件事件，但未知格式只刷新规则依赖，不注册源语言或触发无关 TS 全扫。pubspec 同时参与 YAML 后台刷新，Dart 首次发现不吞掉其文件事件。

JSON/YAML 格式化返回文本 edits，由原生修订校验、撤销和自动保存接手。YAML 使用包内固定 Prettier standalone/插件，不调用项目配置发现。锚点重命名沿用先预览后应用，不引入命令式写入。

## 影响与验收

JSONC 保留注释，尾逗号以固定服务实际返回的警告呈现。基础编辑仍可离线/无 Node 使用；缺工具、规则读取失败和超限明确显示。未保存 Schema 缓冲不代替磁盘依赖规则，关闭自动保存时需要保存规则文件。

当前格式、功能、资源预算与后台入口见[配置工具](../CONFIGURATION_TOOLS.md)；来源/通知见[依赖台账](../DEPENDENCIES.md)。TOML/XML/JSON5 语义、自定义关联设置、在线规则开关和完整配置规则库继续分批实现。后台协议和模型不能替代真实窗口、输入法、性能或发布验收。
