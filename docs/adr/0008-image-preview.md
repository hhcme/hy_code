# ADR 0008：独立只读图片会话与后台解码

- 状态：已接入，后台验证；真实窗口待验收
- 日期：2026-10-23

## 背景

用户要求图片直接预览、缩放，暂不编辑。之前所有文件都进入文本解码，图片只显示编码错误；将图片挂在文本文档上会混淆保存、撤销和语言服务所有权。

## 决策

- 图片和文本在打开入口分派，`EditorWorkspace` 分别拥有图片与文本文档，复用文件标签/历史。图片不创建 Rust TextDocument，不参与自动保存和语义修改。
- 图片字节读取和 ImageIO 解码在共享 utility 串行 worker 执行；安全读取使用已授权根的描述符，不把可再次解析的 URL 直接交给解码器。
- 位图采用系统 ImageIO/CoreGraphics；SVG 采用固定 resvg 0.48.1、roxmltree 0.21.1，通过小型、配对释放的 C ABI 返回不可变预乘 RGBA8。
- 活动标签才保留像素，切走保留纯查看状态；取消/代次检查拒绝旧结果。同步原生调用无法强制中断，预算与取消边界明确记录。
- AppKit 固定视口执行缩放/平移，滚动范围不创建巨型绘图位图；SwiftUI 只绘制工具条和错误/加载状态，不接管正式文本。

## 影响与验收

新增 52 项 Cargo 直接/传递依赖，原始许可和锁定校验随仓库、开发包保留。SVG 受限子集、位图大小、首帧、内存和旧系统边界见[图片预览](../IMAGE_PREVIEW.md)。不接入 WebView、脚本、外部资源或图片编辑器，也不引入自动打开外部预览应用。

格式、取消、路径、FFI、几何与内存检查在无 GUI 入口执行；真实绘制、焦点/键盘/捏合、VoiceOver、帧率、旧系统和大型图片仍需后续验收。
