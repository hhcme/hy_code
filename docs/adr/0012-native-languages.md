# ADR 0012：Swift / Java 语义服务与离线 SQL

- 状态：接受，2026-10-23
- 范围：外部 SourceKit-LSP、Eclipse JDT LS 和内置 SQL 解析/项目 DDL

## 决策

保留 TextKit/Rust 正式文档、原生撤销与安全保存；三种语言各有一个工作区服务所有者，共用受限发现/监听和统一问题/导航/编辑预览。Swift/Java 采用外部官方语言服务，按工作区明确项目执行信任后才加载 SwiftPM/BSP/Maven/Gradle 模型。Xcode 构建信息委托现有兼容 BSP；不复制 IDE 私有内核，不安装 SDK/服务器。SQL 使用固定 Apache-2.0 sqlparser-rs 在单个有界后台工作线程解析，只有离线语法、格式化和 AST 绑定的项目 DDL 投影，不连接数据库。

同步、诊断和请求绑定工作区代次、文档身份与修订；单个有界诊断解析队列合并最新 URI。外部服务 URI 物理路径单独投影，不修改正文。Java 缓存必须在项目外，任意反向写入/命令拒绝；固定整理导入返回的文本修改进入现有预览。原始许可与传递构建依赖固定登记。

## 取舍与验收

项目导入可能读取配置、解析依赖并执行构建脚本，因此 Swift 与 Java 默认不信任；SQL 可直接离线使用。本阶段不是完整 Xcode/IntelliJ/数据库 IDE。真实服务的生成样本和纯模型/FFI 回归可静默运行；窗口、真实工程、外部 Gradle/BSP 提供方及性能分别保持未验证。具体能力、预算、来源和未支持语义见[专题](../NATIVE_LANGUAGES.md)。
