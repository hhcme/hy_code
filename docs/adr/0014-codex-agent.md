# ADR 0014：独立 Codex 运行时与原生多会话

- 状态：首批采用，真实服务/窗口/发布待验证
- 日期：2026-10-26

用户要求系统全局 Codex 保持官方配置，HyCode 接自定义服务，并在右侧提供专用图标和多个并行对话。

采用固定版本的官方原生 Codex app-server，通过独立 Swift JSONL actor 连接；不用可视终端承载协议。每个项目拥有应用私有配置，每个对话拥有独立 CODEX_HOME 和官方线程身份；模型凭据由 HyCode 自有本地文件适配拥有（目录 0700、记录 0600），不读写系统钥匙串或系统登录。

两个只读任务可以并行，修改任务独占项目并冻结已保存的原生文档；后台进程回收后再释放和重载。正式文本/撤销所有者不改变，不建立第二份可写缓冲。外层 Seatbelt 限制 Agent 文件访问，内层运行时控制命令；不提供全盘模式。详细边界、预算和代码地图见[内置 Codex](../CODEX_AGENT.md)。

build 43 增加 DeepSeek 原生 Responses 预设、max 与 1M 元数据以及项目/对话上下文覆盖。应用状态使用跨进程租约；外部配置工具始终只写独立交接文件，由下次项目打开时合并，保留旧窗口的晚到草稿。真实连通只做不提供工具的原生固定请求，Agent 工具环路继续用本机替身。

暂不实现 worktree 合并、统一跨文件撤销、附件、全部桌面插件/云能力。真实模型工具环路、App 内本地凭据、用户窗口、性能、旧系统和正式签名分别保留验收缺口，不以本机替身替代。

2026-10-28 修订：用户明确拒绝系统钥匙串和密码授权交互。API Key 改由应用私有目录中的有界 UTF-8 文件保存，不提供系统凭据回退；宽工作区也须在 Agent 文件沙箱中排除凭据目录及其祖先的移动。旧系统条目不自动读取、迁移或删除，现有用户配置通过显式输入重新保存。
