## 分层与职责

build 36 的 JSON/YAML 配置服务使用自有固定启动适配器；离线 Schema 字节只来自随包固定数据，本地 Schema 通过原生连接的受限反向请求读取。连接记录有界规则依赖，保存/磁盘事件和全量重查清除服务缓存；非标准扩展名的规则事件不注册为源语言，也不触发无关 TS 全扫。格式化仅返回原生文本修改，不调用项目插件。决策与预算见 [ADR 0010](adr/0010-configuration-tools.md) 和[配置工具](CONFIGURATION_TOOLS.md)。

build 28 已增加 [Web 多服务与修改预览](WEB_TOOLS.md)，决策见 [ADR 0007](adr/0007-web-tooling.md)。`EditorLanguageController` 统一原生交互，`WebWorkspaceController` 拥有同步、诊断和包任务；`WebLanguageServer` actor 惰性拥有六类服务（build 36 增加 YAML）。阻塞 pipe/read/wait 在独立 utility 队列执行，写入使用串行队列，不占用 Swift cooperative executor 等待管道。

Web 编辑请求绑定工作区编辑代次。`LSPWorkspaceEdits` 在后台校验本地路径、UTF-16 范围和预算；`EditorWorkspace` 持有预览文档，拒绝未同步脏目标，应用前再次检查 UUID/修订/权限。修改走原生 insertText 与各文档撤销，不新建正式缓冲，不声称跨文件磁盘原子提交或统一撤销。

| 层 | 建议职责 | 边界 |
| --- | --- | --- |
| Swift 原生宿主 | macOS 窗口、项目树、编辑视图、工具窗口、IME、菜单、无障碍 | 不承载重型扫描、解析或索引 |
| macOS 系统适配 | 文件授权/监听、系统剪贴板、文件协调、进程与终端、原生预览 | 明确系统授权、文件身份和访问生命周期 |
| Rust 内核 | 工作区、文档身份与事务、搜索/解析调度、后台任务、状态持久化 | 不创建窗口，不依赖某一 UI 框架 |
| 引擎与服务 | 语法解析、LSP、Git、归档、调试适配 | 按需加载，可取消，可降级，独立记录许可与版本 |

项目按能力逐步建模块；编辑、工作区、文件访问、后台任务和服务生命周期分别明确所有者，避免跨模块全局状态或 UI 直接调用解析器。

图片由 `ImagePreviewDocument` 单独拥有只读会话，后台串行 actor 完成安全读取、ImageIO 解码或 Rust resvg 栅格化；主线程只绘制已解码像素和更新几何。非活动标签释放像素，取消/会话代次隔离旧结果；不建立文本、撤销或自动保存。预算、FFI 所有权和当前格式见[图片预览](IMAGE_PREVIEW.md)与 [ADR 0008](adr/0008-image-preview.md)。

视频独立于图片/文本；`VideoPreviewDocument` 拥有原生播放器和观察器，后台固定描述符经私有资源 delegate 分段供给 AVFoundation，元数据异步加载，原生播放层呈现帧。生命周期与限制见[视频预览](VIDEO_PREVIEW.md)和 [ADR 0009](adr/0009-video-preview.md)。

## 文档、缓冲与撤销

当前由 Rust TextDocument 管理正式文本和修订；AppKit TextKit 1 视图保存输入投影与选择/滚动状态，通过 NSTextStorage 精确传递 UTF-16 增量。每文档原生 UndoManager 独占撤销历史，Rust 不再建立第二套历史。非 MainActor 的 NativeTextDocument actor 串行拥有句柄与磁盘基线并执行文件 I/O；UI 以有序任务提交编辑和保存。默认 800 ms 自动保存，可在设置关闭。实现和边界见 [ADR 0003](adr/0003-text-editing.md)。

无论最终采用哪种存储适配，只允许一个正式缓冲与撤销历史的所有者；原生输入组合态可暂存在平台层，提交为可追溯事务，不能让平台 UndoManager 和 Rust 各自独立重放同一次编辑。Swift/Rust 传递按修订号定位的增量和所需片段，避免每次输入或光标移动都复制整篇文档；缓存不得成为第二个独立可写的正式缓冲。文件身份与显示路径分开，重命名、别名、工作区关闭与服务响应统一按会话身份处理。

保存基于文档修订与磁盘版本检查，平台文件协调/临时写入/落位失败保留缓冲。外部修改不能静默覆盖。预览的截断文本不得作为完整保存输入；草稿、文件内容与工作区布局分别持久化，明确格式版本与恢复路径。

## 后台任务和大文件

当前语法树随正式文档增量更新，Rust 不持有第二份文本；Swift 只请求修订绑定的可见范围，以布局临时属性应用颜色，原生 Undo/IME 归属不变。行号以输入投影的分块 UTF-16 索引维护，只绘制可见逻辑起点；高亮/嵌入语法的大小、数量和协作耗时预算见 [ADR 0004](adr/0004-line-numbers-syntax.md)。

任务具有 ID、代次、进度、取消、终态和清理责任；UI 只接收当前会话有效的结果。I/O、搜索、解析、索引和格式解码离开 UI 线程；使用 async 本身不能证明同步工作已离开主线程。

按需读取、分页/分块和增量解析，不把整个工作区一次加载到内存。已知总量显示真实进度，否则显示阶段与转圈；取消后阻止旧响应和旧任务改写新会话。索引和缓存设资源预算、失效及回收策略，不复制外部项目的固定阈值作为本项目上限。Rope 等内存数据结构不自动提供超内存文件的编辑能力；大文件模式和边界单独设计。测量规则见[性能设计](PERFORMANCE.md)。

## 服务与工作区

工作区保存用户授权、目录根、文档身份、工具链和范围。LSP 作为独立长生命周期服务，由管理器处理启动、协议、取消、崩溃、空闲回收和关闭；文档位置按协商编码转换，所有请求绑定修订。终端、Git、调试和任务采用独立适配，不让一次文件预览默认启动整套工具。

当前目录读取由两个后台 actor 通过共享 FIFO 限定并发，不让一个慢目录阻塞全部请求；取消令牌跨线程置位，但正在执行的系统文件调用仍须等待返回。排队取消也要等一个工作器空闲才能结束。MainActor 按目录修订刷新 NSOutlineView 的变化分支；刷新后显式恢复可见展开分支的读取，不依赖原生重复展开回调。目录选择与文件标签分开建模，不维护中央目录表格。

最近项目由 Swift 工作区拥有，最多保存 30 条标准化路径、徽标派生数据和可选访问书签；书签生成/解析离开主线程，访问仍由 WorkspaceAccess 管理并被在途任务保活。读取失败保留原位错误与重试，不把记录路径视作永久授权。

同一记录保存可空的启动项目路径：打开更新，显式关闭清空；旧数据缺少字段时迁移历史首项，显式空值不会重新迁移。场景首次出现只尝试恢复一次，用户主动打开/关闭/切换会消费恢复机会；后台解析结果仍按项目意图校验，不能覆盖较新的操作。不新增第二个工作区或文件访问所有者。

当前已把 Rust 内核、macOS 宿主、C 头文件、Swift 包、测试和工具分开组织，源码地图见[工作台说明](WORKBENCH.md)。基础编辑、保存与语法着色已接入，Dart LSP、依赖、问题和结构面板已接入；Flutter 运行/调试、测试/构建和基础 Inspector 首批工具采用独立运行所有者和 SDK DAP，见 [ADR 0006](adr/0006-flutter-runtime.md)。终端使用原生视图、独立 PTY helper 和会话所有者，见 [ADR 0015](adr/0015-native-terminal.md)。实际依赖与候选按[依赖台账](DEPENDENCIES.md)分别管理，各专题保留未实现与未验收项。

项目后台诊断的单所有者、后台扫描/监听、原生覆盖与服务缓存交接、依赖范围和 UI 快照预算见[项目后台诊断](PROJECT_ANALYSIS.md)。工作区原生缓冲不因分析器的文件监听自动重载。

Markdown/HTML 使用同一正式文本的修订绑定只读投影；后台 Rust 渲染、原生受限资源 actor 与按活动标签拥有的 WebKit 预览分离。NSSplitView 直接布局，主工作台仍为原生界面。资源路径、网络阻断、隔离滚动桥及预算见[ADR 0011](adr/0011-markup-preview.md)。

## build 40：磁盘文档与原生分段投影

用户确认经常处理超过 1 GB 的文本；采用 Rust 磁盘 piece table、原生有界页、独占跨页历史和后台整文件查找/完整原子保存。所有扩展名共享大小/长行路由，局部页不得用于全文 LSP 修改。范围、资源预算、真实 GB 后台样本与连续滚动/全局行号/窗口性能缺口见[大文件专题](LARGE_FILES.md)和[ADR 0013](adr/0013-disk-backed-text.md)。

Codex build 45 的工具元数据、公共思考摘要和只读差异由同一会话持有。协议文本/活动投影与差异统计在 utility 任务完成，主线程按运行身份回写协议字段，保留期间输入的草稿/标题；滚动观察只连接当前聊天的原生 ScrollView。状态修订驱动分组与汇总更新，不引入第二个消息或文件所有者，见[内置 Codex](CODEX_AGENT.md)。

2026-10-28 按用户明确要求，Codex 凭据由应用本地文件 actor 拥有，不使用 Security/LocalAuthentication 的钥匙串 API。目录 0700、记录 0600，按账户哈希命名，采用不跟随链接的目录相对 FD、短跨进程租约和原子替换。它是本地文件权限隔离，不宣称系统钥匙串加密；不把密钥写入项目状态、参数或日志，Agent 沙箱另外拒绝凭据目录访问和祖先移动，见[内置 Codex](CODEX_AGENT.md)。
